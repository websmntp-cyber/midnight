GOL ARENA FUTSAL - 10 DESAIN, 10 WEBSITE (satu kode, satu repo, 10 proyek Vercel)

CARA KERJA
  Semua website memakai kode yang sama. Desainnya dipilih oleh variabel THEME di
  tiap proyek Vercel (file scripts/build-theme.mjs membuat public/assets/theme.css
  saat build). Data tiap website dipisah oleh SITE_ID di database yang sama.

VARIABEL ENV PER PROYEK (Vercel -> Settings -> Environment Variables)
  THEME      salah satu: midnight-emerald, deep-navy-cyan, obsidian-gold,
             aurora-sport-glow, royal-violet-night, carbon-fiber-frost,
             crimson-arena-glass, arctic-ice-dark, solar-flare-dark,
             minimal-smoked-glass
  SITE_ID    nama unik per website (pakai nama tema); memisahkan data antar website
  ADMIN_KEY  kunci admin (>=16 huruf kecil/angka/strip). Tanpa ini admin ditolak.
  KV_REST_API_URL, KV_REST_API_TOKEN   dari Upstash Redis (sama untuk semua proyek)

ALAMAT
  Website : https://<proyek>.vercel.app/
  Admin   : https://<proyek>.vercel.app/a/<ADMIN_KEY>/
  Cek     : https://<proyek>.vercel.app/api/health
